Шаг 4. Списки устройств

Для каждой пары «тип × интерфейс» со шагов 1–2 создаётся строка загрузки (можно добавить ещё). В файле — один заводской номер на строку (макс. 399).

Шаг 6. RFs — группы и запись

Распределите устройства по RF-группам (до 32). На стыках соседних групп нужны пересечения, чтобы радиосигнал проходил между участками.

Выберите готовый вариант или перейдите к ручной настройке на следующем этапе.

Группы по диапазонам Делит устройства на равные сегменты: первый — только группа 1, средние — стыки соседних групп, последний — связка с предыдущей (группа N через N−1).

Отметьте группы самого RouterRF (обычно группа 1). Остальные участки связываются цепочкой стыков (1+2 → 2+3 → …) и доходят до главного RF. Выбор запишется вместе с узлами.
